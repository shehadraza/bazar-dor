 BazarDor 

BazarDor is an online shopping website that I built using Next.js. The main purpose of this project is to make it easy for users to browse products, find products by category, and manage their accounts.

 Features

1. View Products** – Users can browse products and see product details.
2. Product Categories** – Users can explore products by different categories.
3. User Login and Signup** – Users can create an account and sign in.
4. Profile Update** – Users can view and update their profile information.
5. Responsive Design** – The website is designed to work on desktop, tablet, and mobile devices.

 Technologies Used

 JavaScript

Key Features

Market Price Checking – Users can check the prices of different products in the local market.

Daily Price Updates – Product prices can be updated regularly to show the latest market prices.

Price Comparison – Users can compare prices of products from different markets.

Product Search – Users can easily search for products by name or category.

Latest Market Information – Users can get updated information about product prices and market conditions.
